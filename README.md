# 🐍 Errores en Python — Guía de referencia

> *Python nunca miente. A veces solo grita en rojo.*

Un `Traceback` no es un enemigo — es el intérprete diciéndote exactamente dónde mirar. Este repositorio reúne, en un solo lugar, los tipos de errores que existen en Python y cómo reconocerlos antes de que te hagan perder una tarde entera.

## 🎯 Por qué existe esto

No todos los errores son iguales, y tratarlos igual es la forma más rápida de perder tiempo debuggeando lo que no es. Saber **qué tipo de error tienes enfrente** es el primer paso para saber **dónde buscar la solución**.
